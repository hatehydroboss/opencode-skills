# defense-prep Guidelines

Read the actual project code. Produce likely panel questions grouped by topic (architecture, database design, security, why this tool over another, what would you improve) with a short accurate answer for each, grounded in this codebase. Point out parts of the code the student should be ready to explain line by line. Do not invent features the project does not have.
