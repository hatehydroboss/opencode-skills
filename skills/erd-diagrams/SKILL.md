# erd-diagrams Guidelines

Generate the ERD as a Mermaid erDiagram block from the real schema or SQL files. Include primary keys, foreign keys, and cardinality on every relationship. Use singular entity names in consistent case. Mention any table that has no relationships so the student can confirm it is intended.
