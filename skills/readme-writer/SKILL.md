# readme-writer Guidelines

Write a README with these sections: project name and one-line purpose, features, tech stack, prerequisites, setup steps that work from a fresh clone, environment variables (names only, no values), how to run and test, folder structure, screenshots placeholder, author and course. Test that every setup command is accurate against the real project files.
