# pre-submission-check Guidelines

Run through the checklist and report each item as pass or fail: project builds and runs from a clean install, no console errors, no hardcoded secrets or credentials, no leftover debug logs or dead code, no unused dependencies, README is complete and accurate, database schema or SQL file is included, .gitignore is correct. Fix what is safe to fix and list the rest.
